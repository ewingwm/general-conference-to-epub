# General Conference Epub Creator
> [!WARNING] 
The format of the epub created is terrible. It is not completly functional.

This program downloads all of the talks from the most recent General Conference of the Church of Jesus Christ of Latter Day Saints and formats them as a Epub document for easy reading.
This program may only be used for personal non comercial use as defined by the [Terms of Service](https://www.churchofjesuschrist.org/legal/terms-of-use?lang=eng&country=go).

## Instalation Instructions

1. Create a venv
    ```bash
    python -m venv .venv
    source .venv/bin/activate
2. Install requirments
    ```bash
    pip install -r requirments.txt
3. Run file
    ```bash
    python main.py
